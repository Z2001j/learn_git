# ProcessEngine 流程编排平台 · 文档中心

一个基于 **Java 21 + Spring Cloud 微服务 + Vue 3** 的通用型流程编排平台，覆盖三类核心场景：
**审批工作流**、**任务/服务编排**、**数据与系统集成**。

执行内核为**自研轻量令牌驱动引擎**，采用 BPMN 风格建模（JSON 为主模型，BPMN 2.0 XML 作为导入导出适配格式）。

## 30 秒了解架构

```mermaid
flowchart TB
  C["控制台 / 工作台 / 外部系统"] --> G["process-gateway :8080<br/>路由 · JWT · 限流 · 灰度"]
  G --> IAM["process-iam<br/>租户·用户·权限"]
  G --> DESIGN["process-design<br/>流程·版本·表单"]
  G --> ENGINE["process-engine<br/>执行内核·人任务"]
  G --> SCHED["process-scheduler<br/>调度触发"]
  G --> INTEG["process-integration<br/>连接器·数据源·凭证"]
  G --> NOTIFY["process-notify<br/>模板·渠道·消息"]
  G --> TRACE["process-trace<br/>审计·轨迹·统计"]
  ENGINE -. MQ 指令 .-> WORKER["engine-worker<br/>异步执行 · 可独立扩缩容"]
  ENGINE --> MY[("MySQL 7 库")]
  WORKER --> MY
  ENGINE --> RD[("Redis<br/>缓存·锁·时间轮")]
  WORKER --> RD
  ENGINE -. 事件 .-> MQ[["RocketMQ"]]
  MQ -.-> TRACE
  TRACE --> CH[("ClickHouse")]
```

**三条设计主线**：

1. **令牌驱动**——流程实例是一张图，`Token` 是执行指针；引擎不断取出活跃令牌交给节点行为执行，遇到等待态就停、被唤醒就继续。所有唤醒最终都收敛到一条统一的「推进指令」，便于排查。
2. **不用分布式事务**——跨服务一致性 = 本地事务 + Outbox + 幂等消费 + 补偿 + 三层对账。**Redis 不是正确性依赖**，它挂了引擎降级但不数据错乱。
3. **引擎语义可单测**——`engine-core` 对 Web 与 ORM 零依赖，持久化通过仓储接口反转，节点行为通过 SPI 注册。新增节点类型不改内核代码。
